  kural artik `\n`'i de acikca kapsayacak sekilde guncellendi.
* COZUM: Tum `'...\n...'` JS string literalleri `'...\\n...'` olarak
  duzeltildi (cift backslash - boylece Python'dan JS'e LITERAL `\n`
  gider, JS bunu kendi icinde newline olarak yorumlar).

Rev-28 (2026-03-19) — REST API: /metraj ve /gantt Endpoint'leri (puantaj_api.py)
================================================================================
AI danismaninin Excel okuyup dogrudan sisteme veri yazabilmesi icin eklendi.

Yeni Endpoint'ler (insaat_metraj.db uzerinde calisir):

  METRAJ:
    POST /metraj/kalem-ekle
         { poz_no, is_kalemi, miktar, birim, birim_fiyat, kategori, proje_id }
         -> { success, id, toplam }

    POST /metraj/toplu-ekle
         { proje_id, kalemler: [...] }          <- AI asistan buradan 22+ kalemi tek istekte gonder
         -> { success, eklenen, hatalar }

    GET  /metraj/kalemler?proje_id=<id>[&kategori=<k>]
         -> { proje_id, toplam, kalemler: [...] }

  GANTT:
    POST /gantt/gorev-ekle
         { poz_no, is_kalemi, metraj, birim, calisan, sure, oncul, baslangic_gun, proje_id }
         sure=0 ise CŞB verimliliginden otomatik hesaplanir (3 usta varsayimi)
         -> { success, id, sure_gun }

    POST /gantt/toplu-ekle
         { proje_id, gorevler: [...] }          <- FS bagimlilik zincirleri dahil
         -> { success, eklenen, hatalar }

    GET  /gantt/gorevler?proje_id=<id>
         -> { proje_id, toplam, gorevler: [...] }

    DEL  /gantt/gorev/<id>
         -> { success, message }

  Diger:
    - init_gantt_metraj_tables() run_server() icinde cagrilir (gantt_gorevleri tablosu)
    - Sunucu baslarken tum endpoint'ler konsola yazilir
    - Kimlik dogrulama: X-API-Token header veya Basic Auth
